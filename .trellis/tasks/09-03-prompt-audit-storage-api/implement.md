# 存储与管理 API 实施步骤

## 前置输入

必须在 `prompt-audit-core` 完成并冻结接口后开始。

## 步骤

1. 实现 Option 读取和事务 CAS，调用 `lockForUpdate(tx)`。
2. 在通用 GetOptions 中排除配置键，在通用 UpdateOption 中拒绝配置键。
3. 定义事件模型、跨库 LongText 和查询索引，加入 `migrateDB()`。
4. 实现 EventStore、列表/详情 DTO 转换、完整原文加解密和必要写入失败关闭。
5. 实现分页筛选、单条删除、批量删除和小批量过期清理。
6. 在 master 节点启动配置刷新和自动清理服务。
7. 注册 Root 管理路由并实现配置、运行状态、探测和事件 Controller。
8. 添加权限、脱敏、CAS、加密、清理和 API 合约测试。
9. 完成三数据库真实实例迁移与行为测试，记录版本和命令。

## 交付接口冻结点

完成后冻结管理 API JSON 契约和事件存储语义，前端与所有协议接入子任务以该版本为准。
