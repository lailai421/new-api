# 提示词审计集成与数据库验证

## 目标

在所有实现子任务完成后执行独立质量门禁，证明全入口无法绕过审计、计费时序正确、敏感数据不泄漏且三数据库兼容。

## 依赖

- 依赖父任务 `09-03-prompt-audit`。
- 强依赖以下子任务全部完成：
  - `09-03-prompt-audit-core`
  - `09-03-prompt-audit-storage-api`
  - `09-03-prompt-audit-http-relay`
  - `09-03-prompt-audit-realtime`
  - `09-03-prompt-audit-task-plugin`
  - `09-03-prompt-audit-web-console`
- 本任务不得在依赖未完成时宣称通过。

## 范围

- PRD/设计/实现逐项映射审查。
- 所有 HTTP、Midjourney、Realtime、视频和 Task Plugin 入口的绕过测试。
- Guard、事件持久化、预扣费和业务上游的执行顺序。
- Root 权限、配置脱敏、完整提示词详情与日志防泄漏。
- SQLite、MySQL 5.7.8+、PostgreSQL 9.6+ 新建、升级和重复迁移矩阵。
- Go 与前端全部质量命令。

## 验收标准

- [x] 每个提示词入口都有 Pass、Block 和基础设施错误的可观察回归测试。
- [x] 所有拒绝路径的业务上游调用和预扣费次数均为零。
- [x] Realtime 首个危险帧不会建立业务上游，后续危险帧不会被写入上游。
- [x] 第三方插件缺少审计契约时失败关闭。
- [x] 通用 API、普通日志、前端列表和查询缓存均不含完整提示词或 Token。
- [x] 三数据库完成空库、发布版升级、重复迁移、长文本、CAS、分页和清理验证。
- [x] 后端与前端质量命令全部通过。
- [x] 未完成任何一项真实数据库验证时明确报告阻塞，不声明任务完成。
