# 提示词审计前端控制台

## 目标

在系统设置“安全与限制”下提供提示词审计运行状态、策略、节点池和事件管理页面。

## 依赖

- 依赖父任务 `09-03-prompt-audit`。
- 强依赖 `09-03-prompt-audit-storage-api` 已冻结管理 API DTO、错误码和分页契约。
- 不依赖各协议接入代码，可在管理 API 契约冻结后并行开发。

## 范围

- 路径 `/system-settings/security/prompt-audit` 和安全菜单子项。
- 运行状态、策略配置、节点池、事件四个页签。
- 全部/指定分组、九类风险、完整/最新轮、Pass 留存和保留期配置。
- 节点增删改、write-only Token、优先级顺序和探测。
- 事件筛选、分页、详情按需加载、完整提示词复制、单条/批量删除。
- en、zh、zh-TW、fr、ru、ja、vi 国际化。

## 不包含

- 后端业务逻辑。
- 新增 UI 框架或组件依赖。
- 普通用户访问审计事件。

## 验收标准

- [ ] 菜单、深链接、刷新和 section 导航正确。
- [ ] 配置使用 React Hook Form + Zod，条件校验与后端一致。
- [ ] Token 只允许新建/替换/清空，不显示已有明文或密文。
- [ ] 事件列表不包含完整提示词；详情打开时才请求，关闭后清除缓存。
- [ ] degraded、CAS 冲突、节点失败和权限错误有明确提示。
- [ ] 删除使用 destructive 二次确认，批量最多 500 条。
- [ ] 风险结果同时使用文本和样式表达，键盘与焦点行为可用。
- [ ] 七种语言无缺失键，测试、类型检查、lint、格式和构建通过。
